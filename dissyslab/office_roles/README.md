# Built-in roles (DisSysLab 2.0)

The roles an office can use without writing them, in the form of spec
section 4: front matter (`emits`, `in`, `out`) and, for an English role,
the text the model receives, unchanged. To adapt one, copy it into your
office's `roles/` folder under a new name and edit it (spec 4.2).

At the 2.0 release this folder replaces `dissyslab/roles/`.
