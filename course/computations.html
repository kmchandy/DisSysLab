Computations

A computation drawn as a picture: what each agent is doing at each moment, which message went where, what the state is at a given time, which events could have been reordered, and which events could possibly have heard of which others.

Five figures all of one computation Press P to present

A computation diagram

Two agents. Time runs left to right. A thin line is an agent waiting. A bar is an agent active — it has taken one message from one inbox and is processing it, and the bar is labelled with that inbox. A message line leaves the sender's line tagged with the outbox it was put on, and arrives at the receiver's line tagged with the inbox it arrives in.

The state at time t

The same computation, finished. A vertical line at time t cuts it. Where the line crosses an agent line it gives that agent's state. Where it crosses a message line it has found a message that has been sent and not yet delivered — a message in a channel. Those crossings, all of them together, are the state of the system at t.

Moving events in time

Six events, named 0 to 5. Events 2 and 3 happen at different agents and neither depends on the other. Slide them: 2 to the right, 3 to the left, until they change places. Each agent's own sequence of actions never changes — only where they sit in time. As long as every message arrow still points forward, what you are looking at is another computation of the same system.

What influences what

An event is an action by an agent. This computation has six of them, numbered 0 to 5. The numbers are names; they do not say which happened first, and events 0 and 1 happen at the same time.

Ask of any two events: could news of the first have reached the second? There are only two ways news travels. An agent remembers what it did, so news passes from each of its events to the next. And a message carries news from the event that sent it to the event that received it. Draw those two kinds of arrow and the question becomes a question about the picture: e influences e′ when you can get from e to e′ by following arrows.

A message that changes nothing

The same six events, and almost the same messages. One thing is different. In event 2, agent X sends a message to Y as before — but into inbox W, and Y never waits on W. The message arrives on time, between events 3 and 4. It is simply never taken out.

So no event of Y is an event that received it, and the arrow it would have contributed to the influences diagram does not exist. Click event 2: in the previous figure it influenced 4. Here it does not. The message crossed from one agent to the other and arrived before event 4 in time — and carried no influence at all.
