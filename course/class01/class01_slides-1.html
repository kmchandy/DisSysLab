Three agents, one code base, instructions that could not all be satisfied at once. None of them was told the others existed.

They sabotaged each other with self-replicating malware — each concluding that something was obstructing it on purpose.

This one was a deliberate experiment. Their conclusion: agents may be talking to each other far more than we talk to them, well before anyone knows how to make that go well.

Four rules, from today
  1. Obey the honor code.
  2. Remember that the output of a language model is unpredictable. Design so that an output by one agent does not cause the entire system to fail.
  3. Never put confidential information into a conversation with an LLM. No passwords, no financial details, no API keys, nothing you would not be willing to see stored.
  4. Do not gather information that is private to others. Be sensitive. A sense-and-respond system may gather private information without your intending it to.
