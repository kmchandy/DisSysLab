1. Fair execution: the UNITY model

Part 2 proved two rules about fair paths on any colored graph: the basis rule and transitivity. Now we describe the model of computation of UNITY. A program has a set of states, a set of initial states, and a finite set of actions. Each action is a function from states to states: in every state it has exactly one next state. An action that does nothing in a state takes that state to itself. How actions are written down comes later.

An execution starts in an initial state and runs for ever. At each step one action is chosen and executed. The choice is arbitrary, with one constraint, fairness: every action is chosen infinitely often.

A program is a colored graph
vertex = state    color = action    v →s s(v)

Each action s gives every vertex v exactly one edge of color s, to the state s(v). If s does nothing in v, the edge is a self-loop. Every color is fair.

Part 2 also allows grey edges, whose color is not fair. In a program they are actions that may or may not be executed infinitely often. In UNITY every action is fair.

So an execution is a fair path from an initial state, and ⟦AfF Q⟧ is the set of states from which every execution reaches Q. In UNITY, P ⊆ ⟦AfF Q⟧ is written P ↦ Q and read “P leads to Q”.

The basis rule for a program

In a program, the second part of the condition of the basis rule (part 2, section 3), P ⊆ ⟦¬EfG P⟧, holds when one action takes every state of P out of P. Write ⟦AXs Z⟧ for the set of vertices whose s-edge ends in Z.

One action suffices
P ⊆ ⟦AXs ¬P⟧ for some action s ⟹ P ⊆ ⟦¬EfG P⟧

A fair path takes an s-edge infinitely often. If it stayed in P, its next s-edge would leave P. So no fair path stays in P for ever.

In Figure 1, take P = {0} and Q = {1}. Every edge from 0 ends in 0 or 1, and red takes 0 out of {0}. So by the basis rule {0} ⊆ ⟦AfF {1}⟧: every execution from 0 reaches 1. The adversary can delay red, but not for ever. In the same way, blue gives {1} ⊆ ⟦AfF {2}⟧ and red gives {2} ⊆ ⟦AfF {3}⟧, and transitivity gives {0} ⊆ ⟦AfF {3}⟧.

Notes

UNITY is described in K. M. Chandy and J. Misra, Parallel Program Design: A Foundation (Addison-Wesley, 1988). There the condition of the basis rule is stated for P ∧ ¬Q: P ∧ ¬Q ⊆ ⟦AX (P ∪ Q) ∧ ¬EfG (P ∧ ¬Q)⟧. The conclusion and the proof are the same.
