Part 2. Until and fairness

Part 1 defined AX, AG, AF, EX, EF and EG as sets of vertices of a directed graph G = (V, E) in which every vertex has an outgoing edge. This part uses the same example graph. It adds until, and then restricts attention to fair paths.

1. Until

EF Z says that some path reaches Z, and nothing about the vertices on the way. Until adds a condition on them: the path stays in a set Y until it reaches Z.

E[Y U Z]: on some path, Y until Z
E[Y U Z] = {v | exists path v = v0 → … → vk where vk ∈ Z and v0, …, v(k−1) ∈ Y}

Some path from v reaches Z, and every vertex before it is in Y.

A[Y U Z]: on all paths, Y until Z
A[Y U Z] = {v | for every infinite path v = v0 → v1 → v2 → …, exists k where vk ∈ Z and v0, …, v(k−1) ∈ Y}

Every infinite path from v reaches Z, and every vertex before it is in Y.

k may be 0, so Z is a subset of both. With Y = V there is no condition on the way:

EF Z = E[V U Z]
AF Z = A[V U Z]

In the figure below, let Y = {a, b, c, d} and Z = {f}. Then E[Y U Z] = {a, b, d, f}, because of a → b → d → f; c is not in it, because its only edge goes to e, which is in neither set. And A[Y U Z] = {f}. Two kinds of path show it:

  • from a, the path a → c → e leaves Y before it reaches Z;
  • from d, the infinite path d → b → d → b → … stays in Y and never reaches Z.

Every counterexample to v ∈ A[Y U Z] is one of these two kinds: a path through Y ∖ Z to a vertex outside Y ∪ Z, or an infinite path that stays in Y ∖ Z. Both sets grow from W = Z: add a vertex of Y with some edge into W for E[Y U Z], or with all its edges into W for A[Y U Z].

2. Fairness

AF Z asks that every infinite path reach Z. Fairness lets us ignore some infinite paths. To say which, give every edge a color.

Colored graph
Cfair ⊆ C

Every edge has a color in a set C of colors. The colors in a subset Cfair of C are the fair colors. For every vertex v and every fair color c, there is at least one edge of color c from v; the edge could be from v to itself. A color that is not fair has no such requirement: a vertex may have no edge of that color.

In our examples the fair colors are red (R) and blue (B). Edges whose color is not in Cfair are drawn grey and dashed. When we describe a colored graph, a vertex that has no edge of a fair color c listed has a self-loop of color c.

Infinite path, with colors
(v0, c0, v1, c1, v2, c2, …)

An infinite path from a vertex v is a sequence in which v0 = v and, for each i, there is an edge from vi to vi+1 with color ci ∈ C.

Fair path
every color in Cfair appears infinitely often among c0, c1, c2, …

A fair path is an infinite path in which every fair color appears infinitely often. So, in a fair path, after any number of steps along the path, for every fair color c, there is a later edge in the path that has color c. Edges whose color is not fair, grey in our examples, may appear infinitely often, a few times, or never.

AfF: on all fair paths, eventually
AfF Z = {v | for every fair path (v0, c0, v1, c1, …) with v0 = v, exists k where vk ∈ Z}

For a set Z of vertices, AfF Z is the set of vertices v such that every fair path from v reaches a vertex in Z. The first vertex of the path counts, so a vertex in Z is in AfF Z.

To show that v is not in AfF Z, it is enough to give one fair path from v that never visits Z. From 6, the path that takes the red self-loop forever never reaches 7, but it is not fair, so 6 ∈ AfF {7}, although 6 ∉ AF {7}.

Grey edges. A grey edge into Z does not help. The grey edge 2 → 7 goes straight to 7, but the fair path 2 → 1 → 2 → 1 → … never takes it, so 2 ∉ AfF {7}. And a grey edge may be taken forever. The path 0 → 1 → 0 → 0 → 1 → 0 → 0 → … takes red 0 → 1, grey 1 → 0 and blue 0 → 0 in every round. It uses both fair colors infinitely often, so it is fair, and it never visits {2, 3}. So 0 ∉ AfF {2, 3}. Without the grey edge 1 → 0, every fair path from 0 would reach {2, 3}.

Observations.

  1. Z ⊆ AfF Z
  2. (Y ⊆ Z) ⟹ (AfF Y ⊆ AfF Z)
  3. AfF Y ∪ AfF Z ⊆ AfF (Y ∪ Z), and the two sides can differ. In figure 3, 0 is not in AfF {1, 2}, because of the fair path that goes 0 → 3 and then cycles between 6 and 7; and 0 is not in AfF {3, 4, 5, 6, 7}, because of the fair path that goes 0 → 1 and then cycles between 1 and 2. But 0 is in AfF {1, 2, 3, 4, 5, 6, 7}: a fair path must take red from 0, and both red edges leave 0.

Only F needs fairness Every finite path can be continued to a fair path: from any vertex, take the fair colors in turn. So a vertex is reachable along some fair path exactly when it is reachable. Counting only fair paths changes nothing for AX and AG; it changes AF.

The dual of AfF is (EfG Z) = (¬AfF ¬Z): the set of vertices from which some fair path stays in Z forever. Figure 3 shows such a path whenever it shows a vertex outside AfF Z.

AG AfF Y and AfF AG Y

The two operators can be combined, and the order matters. Here is the smallest example: two vertices, a and b, and two fair colors.

VertexRed edgeBlue edge
aa → ba → a
bb → bb → a

Take Y = {a}.

  • AG Y = ∅, because the edge a → b leaves {a}. So AfF AG Y = ∅.
  • AfF Y = {a, b}: a fair path from b must take blue at some point, and blue goes to a. No edge leaves {a, b}, so AG AfF Y = {a, b}.
  • AG AfF Y is the set of vertices from which every fair path visits Y infinitely often: wherever the path is, it will reach Y again.
  • AfF AG Y is the set of vertices from which every fair path reaches a vertex from which no path ever leaves Y.

Observation. AfF AG Y ⊆ AG AfF Y, and figure 4 shows that the two sides can differ.

Proof

Let v ∈ AfF AG Y, let v →* w, and let P be a fair path from w. Putting the path from v to w in front of P gives a fair path from v, so it reaches some u ∈ AG Y.

If u comes before w, then u →* w, so w ∈ Y. If not, u is on P, and u ∈ Y, because AG Y ⊆ Y. Either way P reaches Y, so w ∈ AfF Y. This holds for every w with v →* w, so v ∈ AG AfF Y.

Composing the operators

AX, AG and AfF each take a set of vertices and give a set of vertices, so they can be composed. Read a composition from the right: AX AG AfF Y first computes AfF Y, then AG of that, then AX of that. The examples use the colored graph of figures 3 and 4.

Y = {7}SetMeaning
AfF Y{3, 4, 5, 6, 7} every fair path reaches 7
AG AfF Y{3, 4, 5, 6, 7} no edge leaves {3, …, 7}, so every fair path reaches 7 again and again
AX AG AfF Y{3, 4, 5, 6, 7} every edge leads to a vertex of the line above
Y = {4}SetMeaning
AfF Y{3, 4} from 3, a fair path must take blue, to 4
AG AfF Y∅ from 4, the edges to 5 and 7 leave {3, 4}
AX AG AfF Y∅ AX ∅ = ∅, because every vertex has an edge

In both examples the last step changes nothing. That is no accident:

Observation AX AG AfF Y = AG AfF Y, for every Y. Visiting Y infinitely often can be neither gained nor lost in one step.

Proof

Let W = AG AfF Y. W is stable, so W ⊆ AX W.

Conversely, let v ∈ AX W. Every fair path from v is in W ⊆ AfF Y after one step, and the rest of the path is still fair, so it reaches Y: v ∈ AfF Y. Every other vertex reachable from v is reachable from a vertex of W, so it is in AfF Y too. So v ∈ AG AfF Y = W.

The order matters. Take Y = {6}. No vertex has all its edges going to 6, so AX {6} = ∅ and AfF AX {6} = ∅. But AfF {6} = {3, 4, 5, 6, 7}, and no edge leaves that set, so AX AfF {6} = {3, 4, 5, 6, 7}. And with Y = {4}, AX AfF {4} = {3}: vertex 4 is in AfF {4}, but its edges go to 5 and 7.

Notes

Note: fixed points

Every operator in this lecture is the largest or the smallest set W that satisfies a condition. Model checkers compute them this way: the largest by peeling from above, the smallest by growing from below.

AG Z: largest W with W ⊆ Z ∩ AX W
EG Z: largest W with W ⊆ Z ∩ EX W
AF Z: smallest W with Z ∪ AX W ⊆ W
EF Z: smallest W with Z ∪ EX W ⊆ W
A[Y U Z]: smallest W with Z ∪ (Y ∩ AX W) ⊆ W
E[Y U Z]: smallest W with Z ∪ (Y ∩ EX W) ⊆ W
