Elements of Temporal Logic

Part 1. Sets of vertices: all paths and some path

Temporal logic describes how a system can behave over time. The possible behaviors of a system are the paths in a directed graph: a vertex is a state, and an edge is a step. This lecture defines the operators of the temporal logic CTL as sets of vertices of a graph, where they can be seen. Part 2 adds until and fairness; part 3 brings in initial states, looks at single paths, and explains the logic LTL.

1. Directed graphs

A directed graph G = (V, E) has a set V of vertices and a set E of edges. We write v → v′ for the edge (v, v′), and v →* v′ when there is a path from v to v′: a sequence v = v0 → v1 → … → vk = v′. A path may have length 0 (k = 0), so v →* v for every vertex v.

We assume every vertex has an outgoing edge
for every vertex v: v → w for some vertex w

We consider only graphs in which every vertex has at least one outgoing edge, so that a path can always be continued. Standard temporal logic makes the same assumption.

Infinite path
v0 → v1 → v2 → …

An infinite path from v is an infinite sequence of vertices with v0 = v and an edge vi → vi+1 for every i. Because every vertex has an outgoing edge, every path can be continued to an infinite path.

For a set X of vertices:

Out-neighborhood
N(X) = {v′ | v → v′ for some v ∈ X}

The out-neighborhood of X is the set N(X) of vertices reached from X by one edge.

Reachable set
R(X) = {v′ | v →* v′ for some v ∈ X}

The set reachable from X is the set of vertices, R(X), reached from X by a path.

The out-neighborhood of the empty set ∅ is the empty set: N(∅) = ∅ and R(∅) = ∅.

Because a path may have length 0, X ⊆ R(X); and N(X) ⊆ R(X). But X need not be a subset of N(X).

Notation: ≡, ⟹ and [ ]

For predicates P and Q, ∧ is and, ∨ is or, and ¬ is not. A set Z of vertices is also the predicate “v ∈ Z”, so ¬Z is the complement of Z: ¬Z = V ∖ Z, the vertices not in Z.

P ≡ Q  is  (P ∧ Q) ∨ (¬P ∧ ¬Q)

P ≡ Q, read “P equivales Q”, is a predicate. It is true when P and Q are both true or both false. For example, it is false when P is true and Q is false.

P ⟹ Q  is  ¬P ∨ Q

P ⟹ Q, read “P implies Q”, is a predicate. It is false only when P is true and Q is false.

[X]

Dijkstra’s square brackets: [X] means that the predicate X holds everywhere in the domain. For example, in the domain of integers, [k > 0 ≡ k ≥ 1]. In these lectures the domain is the set V of vertices. For example, [v ∈ Y ⟹ v ∈ Z] says that every vertex of Y is in Z: it is Y ⊆ Z.

Predicates and truth sets

A predicate on vertices is true at some vertices and false at others. Its truth set is the set of vertices at which it is true. We use the same name for both: a set Z of vertices is the predicate “v ∈ Z”, and a predicate P is the set of vertices at which P holds. Each operator on predicates is then an operation on truth sets:

PredicateTruth setTrue at v when
¬PV ∖ Pv is not in P
P ∧ QP ∩ Qv is in both
P ∨ QP ∪ Qv is in either
P ⟹ Q¬P ∪ Qv is outside P, or in Q
P ≡ Q(P ∩ Q) ∪ (¬P ∩ ¬Q)P and Q agree at v

Notice that P ⟹ Q is true at every vertex outside P. It is false exactly at the vertices that are in P but not in Q.

With and without brackets P ⟹ Q, without brackets, is a predicate: it is true at some vertices and false at others, and its truth set is ¬P ∪ Q. [P ⟹ Q], with brackets, is a single truth value: it is true when P ⟹ Q holds at every vertex, that is, when no vertex is in P but not in Q.

[P ⟹ Q] ≡ (P ⊆ Q)
[P ≡ Q] ≡ (P = Q)

Precedence. ¬ binds most tightly, then ∧ and ∨, then ⟹, and ≡ binds least tightly. So P ∧ Q ⟹ R ≡ S means ((P ∧ Q) ⟹ R) ≡ S.

2. On all paths: AX, AG, AF

CTL names each operator with two letters. The first says which paths from a vertex: A, all of them, or E, at least one (there exists one). The second says what happens on them: X, at the next vertex; G, globally, at every vertex; F, finally, at some vertex. Each operator takes a set Z of vertices and gives a set of vertices. This section is about A, and section 3 about E.

AX

AX: on all paths, next
AX Z = {v | N({v}) ⊆ Z}

For a set Z of vertices, AX Z is the set of vertices all of whose edges end in Z.

So every edge from a set Y ends in Z exactly when Y ⊆ AX Z:

(N(Y) ⊆ Z) ≡ (Y ⊆ AX Z)

A vertex can be in AX Z without being in Z: AX Z says where the path goes next, not where it is now.

stable

stable
stable(Z) ≡ (Z ⊆ AX Z)

A vertex set Z is stable exactly when no edge leaves Z: every vertex of Z is in AX Z.

Equivalently, stable(Z) ≡ (N(Z) ⊆ Z). In graph theory a stable set is called closed, because there is no path from a vertex in a stable set to a vertex outside it.

In the bracket notation, stable(Z) ≡ [Z ⟹ AX Z]. For example, with Z = {b, c, f}, AX Z = {a, d}, so the truth set of Z ⟹ AX Z is ¬Z ∪ AX Z = {a, d, e, g, h, i, j}. It is false at b, c and f, and each of them has an edge leaving Z: b → d, c → e and f → g. So [Z ⟹ AX Z] is false, and Z is not stable.

Observation. stable(Z) ≡ (R(Z) = Z).

AG

AG: on all paths, always
AG Z = {v | R({v}) ⊆ Z}

AG Z is the set of vertices from which every path stays in Z.

Observations.

  1. AG Z ⊆ Z, because v ∈ R({v}).
  2. stable(AG Z)
  3. (Y ⊆ Z) ∧ stable(Y) ⟹ (Y ⊆ AG Z)
  4. So AG Z is the largest stable subset of Z, and stable(Z) ≡ (AG Z = Z).
  5. AG Z can be the empty set.
  6. AG Z is the largest set W with W ⊆ Z ∩ AX W. Figure 6 computes it this way: start with W = Z, and remove vertices that are not in AX W until none is left to remove.

AF

AF: on all paths, eventually
AF Z = {v | for every infinite path v = v0 → v1 → v2 → …, exists k where vk ∈ Z}

AF Z is the set of vertices from which every infinite path reaches a vertex of Z. The first vertex of the path counts, so a vertex of Z is in AF Z.

In the example graph, AF {g, h} = {f, g, h}: the only edge from f goes to g. The vertex e is not in it, because the infinite path e → j → i → j → i → … never visits {g, h}; nor is d, because of d → b → d → b → ….

To show that v is not in AF Z, it is enough to give one infinite path from v that never visits Z. In a finite graph such a path can always be chosen as a lasso: a path to a cycle outside Z, and then round the cycle forever.

Observations.

  1. AG Z ⊆ Z ⊆ AF Z
  2. (Y ⊆ Z) ⟹ (AF Y ⊆ AF Z)
  3. AF Z is the smallest set W with Z ∪ AX W ⊆ W. Figure 7 computes it this way: start with W = Z, and add vertices of AX W until none is left to add. AG is computed from above, by peeling; AF from below, by growing.

3. On some path: EX, EF, EG

The E operators ask for one path rather than all of them.

EX: on some path, next
EX Z = {v | N({v}) ∩ Z ≠ ∅}

EX Z is the set of vertices with at least one edge that ends in Z.

EF: on some path, eventually
EF Z = {v | R({v}) ∩ Z ≠ ∅}

EF Z is the set of vertices from which some path reaches Z.

EG: on some path, always
EG Z = {v | exists infinite path v = v0 → v1 → v2 → … where vk ∈ Z for all k ≥ 0}

EG Z is the set of vertices from which some infinite path has every one of its vertices in Z.

In the example graph, EX {b, c, f} = {a, d, e}, and EF {g, h} = {a, b, c, d, e, f, g, h}: only i and j cannot reach {g, h}. And EG {a, b, c, d} = {a, b, d}: the path a → b → d → b → d → … stays in the set, but the only edge from c goes to e.

AG Z asks that every path stay in Z; EG Z asks only for one. Here is a small graph in which they differ. It has four vertices, p, q, r, s, and edges p → q, q → p, p → r, r → s and s → r. Take Z = {p, q}.

  • EG Z = {p, q}: the path p → q → p → q → … stays in Z forever.
  • AG Z = ∅: from p, the edge p → r leaves Z, and from q, the path q → p → r does.

A and E are duals

Some path does something exactly when not every path does the opposite. Recall that ¬Z is the set of vertices not in Z.

(EX Z) = (¬AX ¬Z)
(EF Z) = (¬AG ¬Z)
(EG Z) = (¬AF ¬Z)

For example, v ∈ EF Z ≡ some path from v reaches Z ≡ not every path from v stays in ¬Z ≡ v ∉ AG ¬Z. Check the third line on the example, with Z = {a, b, c, d}: ¬Z = {e, f, g, h, i, j}, AF ¬Z = {c, e, f, g, h, i, j}, and ¬AF ¬Z = {a, b, d} = EG Z. The same equations, with A and E exchanged, give each A operator from an E operator.

The E operators are computed like the A operators. EF Z grows from W = Z by adding a vertex with some edge into W; EG Z peels from W = Z by removing a vertex with no edge into W.

Notes

Note: CTL

CTL (computation tree logic) is due to Clarke and Emerson. Its formulas are usually written with propositions, such as AG ¬crash, and the meaning of a formula is the set of vertices, or states, at which it holds. These lectures work with those sets directly: a proposition is a set of vertices, and each operator maps sets to sets.
